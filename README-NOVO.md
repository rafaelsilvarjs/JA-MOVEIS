# JÁ Móveis Planejados - Site Profissional

Um site moderno e responsivo para apresentar serviços de móveis planejados, desenvolvido com **React**, **TypeScript** e **Tailwind CSS**. Agora com **galeria de imagens** e **vídeos demonstrativos**!

## 🚀 Características

- ✅ Design responsivo para desktop, tablet e mobile
- ✅ Navegação fluida entre páginas
- ✅ Hero sections impactantes
- ✅ **Galeria de imagens reais dos projetos**
- ✅ **Vídeos demonstrativos com autoplay**
- ✅ **Seção "Antes e Depois" com transformações**
- ✅ Portfólio de projetos com filtros
- ✅ Formulário de contato funcional
- ✅ Integração com WhatsApp
- ✅ Menu mobile responsivo
- ✅ Depoimentos de clientes
- ✅ FAQ animado
- ✅ Botão flutuante de WhatsApp
- ✅ Otimizado para SEO
- ✅ Performance acelerada com Vite

## 📁 Estrutura do Projeto

```
src/
├── assets/
│   ├── images/          # Imagens dos projetos
│   └── videos/          # Vídeos demonstrativos
├── components/
│   ├── Header.tsx       # Navegação e menu
│   └── Footer.tsx       # Rodapé
├── pages/
│   ├── Home.tsx         # Página inicial com galeria
│   ├── Sobre.tsx        # Sobre com equipe e processos
│   ├── Servicos.tsx     # Serviços oferecidos
│   ├── Portfolio.tsx    # Portfólio com filtros e vídeos
│   └── Contato.tsx      # Formulário e contatos
├── App.tsx              # Componente principal
├── main.tsx             # Ponto de entrada
└── index.css            # Estilos globais
```
